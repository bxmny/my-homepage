学习记录

这里按时间倒序记录我每学一样东西的过程：学了什么、卡在哪里、怎么解决。 解决了的标绿，还没解决的标黄——后者会一直留着，提醒我别忘了。

2026 年 11 月

用 HTML + CSS 从零写一个个人主页 已解决

学了什么：HTML 的语义化标签、CSS 的盒模型、Flexbox 布局、CSS 变量。

  • 遇到的问题：导航栏在手机上会挤成一坨，文字换行很难看。
  • 怎么解决的：查 MDN 文档，用 @media 媒体查询写了 @media (max-width: 760px)，把导航改成换行居中。
  • 还没解决的：吸顶导航偶尔会有一点抖动，打算这周看看是不是 body 高度的问题。
2026 年 10 月

C 语言数组：解决越界导致乱码的问题 已解决

学了什么：一维数组的定义、初始化、遍历，以及冒泡排序。

  • 遇到的问题：写了个求 5 个同学平均分的程序，运行后输出总是乱码或者极大值。
  • 怎么解决的：用 printf 一行行查，发现循环条件写成了 i <= 5。数组长度是 5，下标从 0 到 4，越界访问到了未知内存。改成 i < 5 就好了。
  • 学到的教训：数组下标永远是从 0 开始的，千万别多走一步。
2026 年 10 月

第一次用 Git 和 GitHub 管理代码 已解决

学了什么：Git 的 init / add / commit / push 命令，以及连远程仓库。

  • 遇到的问题：第一次 push 报错 rejected — non-fast-forward。
  • 怎么解决的：问同学后明白是远程仓库里有 README，和本地冲突。用 git pull --rebase 先拉下来再推就好了。
