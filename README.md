# 我的成长主页 (My Homepage)

软件工程专业大一学生（2026级）冯奥的个人主页，用来记录大学四年的学习过程、展示技能和项目作品。
这不是一次性作业，而是一个会持续更新的个人空间。

## 项目说明

网站包含 5 个相互跳转的页面：

| 页面 | 文件 | 内容 |
|---|---|---|
| 关于我 | `index.html` | 个人介绍、学习方向 |
| 学习记录 | `learning.html` | 时间线记录（CSS布局踩坑、C语言数组越界、Git报错等） |
| 技能展示 | `skills.html` | 技能进度条 + 真实代码证据（数组冒泡排序、JS表单校验） |
| 项目作品 | `projects.html` | 个人主页项目、C语言成绩统计项目及难点复盘 |
| 联系方式 | `contact.html` | 邮箱、GitHub，以及带 JS 校验的留言表单 |

## 运行方式

不需要安装任何软件或服务器：

1. 将代码下载或克隆到本地文件夹；
2. **双击 `index.html`**，浏览器就会打开首页；
3. 点击顶部导航可以在 5 个页面之间自由跳转。
