证据一：C 语言数组冒泡排序

C 语言 · 课程练习

我用它做了什么：老师要求写一个程序，输入 5 个人的成绩，从低到高排序输出。 这是我在学完双重 for 循环后，自己写出的第一个不报错的排序代码。 

#include <stdio.h>

int main() {
    int scores[5] = {85, 92, 76, 60, 88};
    int i, j, temp;

    // 冒泡排序
    for (i = 0; i < 4; i++) {
        for (j = 0; j < 4 - i; j++) {
            if (scores[j] > scores[j+1]) {
                temp = scores[j];
                scores[j] = scores[j+1];
                scores[j+1] = temp;
            }
        }
    }

    // 打印结果...
    return 0;
}

证据二：JS 表单校验

交互练习 · 用在「联系方式」页

我用它做了什么：联系方式页的留言表单，点提交时会检查邮箱和内容为空， 并用正则表达式判断邮箱格式。这是我第一次用 JS 做真实交互。 

form.addEventListener("submit", function (event) {
  event.preventDefault(); // 阻止页面刷新

  const email = document.querySelector("#email").value.trim();
  const content = document.querySelector("#content").value.trim();
  const msg   = document.querySelector("#form-msg");

  const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailPattern.test(email)) {
    msg.textContent = "邮箱格式看起来不太对，检查一下？";
    msg.classList.add("show");
    return;
  }

  msg.textContent = "已收到，谢谢你的留言！";
  msg.classList.add("show");
  form.reset();
});
