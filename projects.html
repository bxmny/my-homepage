01 · 个人成长主页（本网站）

HTML5 CSS3 JavaScript Git

解决什么问题

学校要求做一个能长期使用的个人主页，用来记录学习过程、展示技能， 以后找实习或参加竞赛时可以直接发给别人看。它不只是一次性作业， 而是一个会陪我走过大学四年的空间。

我负责什么

  • 全部工作由我一个人完成：从页面结构设计、配色、写 HTML/CSS，到用 JS 实现表单校验；
  • 自己规划了 5 个页面（关于我、学习记录、技能展示、项目作品、联系方式）和信息层级；
  • 用 Git 管理版本，并把代码托管到了 GitHub。

用了什么技术

  • HTML5：语义化标签搭建页面结构；
  • CSS3：Flexbox 做布局，CSS 变量统一配色，媒体查询做手机适配；
  • 原生 JavaScript：监听表单提交，校验邮箱格式。

最大的困难

最大的困难是手机端的适配。在电脑上看着很正常的导航栏，到了手机上会挤成好几行。 一开始我不知道怎么办，后来查 MDN 才明白要用媒体查询。 我在 CSS 里加了 @media (max-width: 760px)，在窄屏下把导航改成居中换行， 改完之后手机上看就舒服多了。

02 · 学生成绩统计系统（C 语言）

C 语言 数组 课程练习

解决什么问题

老师布置的练习：用数组存 10 个同学的成绩，输入后计算平均分、最高分、最低分， 并尝试用冒泡排序输出。

我负责什么

  • 独立完成全部代码，包括数组遍历、条件判断和排序算法；
  • 自己设计测试数据，排查越界错误；
  • 记录并整理调试过程中遇到的 bug。

用了什么技术

  • C 语言：一维数组、for 循环、if 条件判断；
  • 调试：用 printf 打印循环变量来定位问题。

最大的困难

最大的困难是数组越界导致的乱码。程序一运行，平均分结果就是一堆乱码或者极大的负数。 我一开始乱改了半小时都没用，后来用 printf 一步步看， 发现循环条件写成了 i <= 10。数组长度是 10，下标应该是 0 到 9， 越界访问到了未知内存。改成 i < 10 之后，结果就完全正确了。 这次经历让我彻底记住了数组下标从 0 开始。
